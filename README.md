# CareFlow — Clinical Pathway Process Mining

## Project Overview
CareFlow analyzes hospital event-log data to understand patient journeys, identify common clinical pathways, and investigate delays between activities.

## Project Objectives
- Understand the sequence of activities in each patient journey.
- Discover and visualize process flows using PM4Py.
- Identify common pathways, alternative routes, and repeated activities.
- Analyze elapsed time between consecutive activities to investigate potential bottlenecks.
- Develop a Power BI dashboard to summarize patient visits, events, activity frequency, and journey duration.
- Validate dashboard figures against the source data and document findings.

## Planned Tools
- Python and Google Colab
- PM4Py
- Pandas and Matplotlib
- Power BI

## Project Structure
- `notebooks/` — analysis notebooks
- `docs/` — methodology and findings
- `powerbi/` — dashboard files and documentation

## Data Privacy
Patient-level data must be handled according to the internship team's data-access and privacy requirements. Raw or identifiable patient data must not be committed to a public repository.
